# Scriptor per a Windows

Versió estable actual: **1.12.2**.

- [Descarregar Scriptor 1.12.2](https://github.com/queco-jones/scriptor-releases/releases/download/v1.12.2/Scriptor-Setup-1.12.2.exe)
- [Canvis i fitxers de la versió](https://github.com/queco-jones/scriptor-releases/releases/tag/v1.12.2)
- [Scriptor Admin 1.12.2 — canal independent](https://github.com/queco-jones/scriptor-releases/releases/tag/admin-v1.12.2)

Scriptor descarrega les actualitzacions de manteniment en segon pla i les aplica amb **Actualitzar i reiniciar**, encara que no hi hagi una llicència activa. Les funcions del programa i l’accés a betes continuen subjectes als permisos de la llicència.

Aquesta versió corregeix l’autorització després d’actualitzar, la memòria cau de llicències desvinculades, els estats de sessió i connexió i les eines de taules. Admin incorpora les correccions de navegació, els filtres i comptadors de codis caducats, i la icona en les mides habituals de Windows.

Admin requereix el compte del propietari. La seva còpia privada també es distribueix al repositori de codi font. Els instal·ladors anteriors es conserven.
